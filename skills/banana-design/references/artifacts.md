# Banana Design · 制品类型与场景策略

不同制品的设计目标不同：幻灯片、长文报告、产品界面、数据大屏、营销页、邮件各有各的关注点；教育、医疗、政务等场景又有不同的松紧。写之前先定目标，再按目标取策略。

**本文件全部内容属于 Banana 默认值**——按通用可访问性要求与常见实践整理，未经多方项目验证，项目规范优先于本文件；引用时按 `SKILL.md` 第 0 节说明类别。

## 一、三步定目标

1. **定制品类型**：先回答"产出来是什么"。产品界面、幻灯片、长文报告、数据大屏、营销页、邮件、打印物，各是一套约束。
2. **定场景与受众**：谁看、在什么设备或距离、看多久。同一个 deck，会议室投屏 3 米外看和手机上翻阅是两种设计。
3. **写一句目标**，格式固定：**「〈受众〉在〈场景〉下，〈时间〉内先看到〈主信息〉，然后〈动作〉」**。写不出来就是还没想清楚，先问，别开工。

例：「经理在周会投屏上，10 秒内先看到 11 月收入与环比，然后决定是否讨论续签风险。」

目标句决定后面所有参数：信息密度、字号基准、色彩强度、动效预算、验收方式。换目标就换参数，不拿一套模板硬套。

## 二、按制品类型选策略

| 制品 | 首要关注 | 关键参数（Banana 默认值） | 最常见的错误 |
| --- | --- | --- | --- |
| 产品界面 | 状态齐全、操作可达、明暗一致 | 4px 网格、组件库复用、正文 12 / 14 / 16 | 把长文的排版习惯带进界面：特大标题、大段文字 |
| 幻灯片 | 投屏可读、一页一个论点 | 1280×720 画布、正文 ≥ 20px、一页一个强色 | 用文档字号做幻灯片，12px 正文投屏看不清 |
| 长文报告 | 阅读舒适、层级清楚 | 正文列 768–860px、报告字阶 11–22px、图表配表格副本 | Markdown 直译成 HTML，无封面无编号无图示 |
| 数据大屏 | 远距离可读、关键指标优先 | 深色底、KPI 字号放大 2–3 倍、动效克制 | 卡片均分不分组，看板变成卡片墙 |
| 营销页 | 一个主行动 | 首屏一句话加一个 CTA，强色只给 CTA | 三四个并列按钮，访客不知道点哪个 |
| 邮件 | 客户端兼容 | 表格布局、系统字体、内联样式、宽度 ≤ 640px | 外部字体、脚本、复杂 grid，被客户端砍掉 |

先定制品，再叠场景：教育场景的幻灯片 = 幻灯片参数 + 教育调整，不另起一套。

## 三、按场景调参

同一制品在不同行业与使用环境下松紧不一样。下表是默认倾向，项目规范优先。

| 场景 | 调整方向 | 硬约束 |
| --- | --- | --- |
| 通用 SaaS | 按本规范默认值 | — |
| 教育 | 字号上调一档；圆角与插画更友好；动效给足反馈；儿童向触控目标 ≥ 48px、每屏文字减半 | 对比度不降 |
| 医疗 | 低刺激配色，避免大面积红；数字必须带单位；关键状态不只靠颜色 | 打印可读；错误与警告不得视觉弱化 |
| 政务/公共 | 高正式度：直角或 ≤ 4px 圆角、既定色板（深蓝、红）、系统字体；信息密度可以高，层级必须清楚 | 正文对比度按 7:1 做；黑白打印可读；不用潮流动效与表情符号 |
| 金融 | 数字用 tabular-nums 对齐；涨跌色遵循当地市场习惯（A 股红涨绿跌） | 披露与风险提示不得视觉弱化 |
| 工业/车载 | 高亮度环境：深色文字浅色底；触控目标 ≥ 48px；状态一眼可辨 | 强光环境截图核验，不只看暗房效果 |

## 四、幻灯片的生产参数

这套值经 2026-11-14 的 14 页 deck 全链路验证（HTML → PDF → PPTX 导出、逐页截图核查）。

- 画布 1280×720（16:9），JS 按窗口等比缩放；hash 路由 `#sN` 翻页；`?slide=N` 单页模式，供逐页截图。
- 打印 `@page { size: 1280px 720px; margin: 0 }`，导出 PDF 每页 960×540pt；PPTX 每页一张全幅图，13.333×7.5 英寸（python-pptx）。
- 字号：正文 ≥ 20px，注释 ≥ 16px，页脚 ≥ 14px，标题 44–64px。验收：导出 PNG 缩到 25% 仍能读出标题。
- 标题写判断，不写栏目名：「曝光到咨询是最大的流失点」，而不是「获客漏斗」。
- 版式至少备两种构图模板（数据页、论点页、章节页）轮换；十几页共用同一骨架会显得机械。
- 结尾页给结论或下一步；附录（口径、明细）放在结论页之后。
- 大数字与图表是主角，说明文字退后；卡片和底色块能不加就不加，层级靠字号与留白。

### 幻灯片专项禁则

- 同一屏并排的条形图必须同一量程。量程不同就上下分区或换图形，不许同高同宽并排——长度会被当成可以横向比较。
- 图表已直接标注数值时不再放同一组数据的表格；无障碍表格副本用视觉隐藏类（`sr-only`）或收进附录。
- 面向业务的制品不出现数据库字段名（`revenue_monthly`、`channel_acquisition` 这类）；口径表只留业务含义列：指标、计算方式。

## 五、验收按制品换

| 制品 | 验收动作 |
| --- | --- |
| 产品界面 | 四态走查、键盘主流程、明暗两套截图 |
| 幻灯片 | 逐页导出 PNG 全部看过；PDF 页数与页尺寸核对；PPTX 回读页数与尺寸 |
| 长文 | 浏览器整页截图看层级与留白，不凭代码想象 |
| 大屏 | 在目标亮度环境看一次 |
| 邮件 | 至少两家客户端预览（Gmail 网页 + Apple Mail） |
| 打印物 | 黑白打印一份再交 |

验收方式写进目标句：改目标先改验收，再动代码。
